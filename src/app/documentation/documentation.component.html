Toast's Attributes

title

Description:

Set the title of the toast.

Values:

String

description

Description:

Set the description of the toast.

Values:

String | Component | { component: Component; inputs: { } };

position

Description:

Define the position of the toast (optional).

Default:

top-right

Values:

top-left | top-center | top-right | bottom-left | bottom-center | bottom-right

duration

Description:

Define the duration of the toast (optional).

Default:

3000ms

Values:

Number

icon

Description:

Define the personalize icon of the toast (optional).

Default:

Depends of the type of toast

Values:

String | Component

styles

Description:

Define the personalize style of the toast (optional).

Values:

{ title: String; description: String, badge: String, button: String }

fill

Description:

Define the fill style of the toast with the hexadecimal color (optional).

Values:

String

button

Description:

Define the button and function (optional).

Values:

{ title: string; onClick: () => { }; }

}
